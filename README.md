# CodeAlpha Internship – Task 1: Image Gallery

A modern, responsive image gallery developed using HTML, CSS, and JavaScript as part of my CodeAlpha Frontend Development Internship.

## 📌 Project Overview

Visuals is a photography gallery website designed to showcase beautiful images with an elegant and interactive user interface. It features image categories, lightbox viewing, and smooth transitions.

## ✨ Features

- Responsive image gallery layout
- Image filtering by categories
- Interactive lightbox view
- Next and Previous image navigation
- Smooth hover effects and transitions
- Keyboard navigation using arrow keys
- Close lightbox using the Escape key
- Modern dark-themed UI
- Responsive design for desktop, tablet, and mobile devices

## 🛠️ Technologies Used

- HTML5 – Structure
- CSS3 – Styling and responsive layout
- JavaScript – Interactivity and functionality
- Unsplash – Photography images

## 🚀 How to Run

1. Clone or download this repository.
2. Open the project folder in VS Code.
3. Open `index.html` using Live Server.
4. Explore the gallery and its interactive features.
